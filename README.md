# 🏸 SmashZone - Badminton Court Management & Booking System

[![PHP](https://img.shields.io/badge/PHP-777BB4?style=flat&logo=php&logoColor=white)](https://www.php.net/)
[![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat&logo=mysql&logoColor=white)](https://www.mysql.com/)

SmashZone is a full-stack web application engineered to streamline the badminton court reservation and facility management process. The platform provides a unified digital ecosystem that bridges sports enthusiasts with facility owners, automating everything from real-time court availability checking to seamless transaction tracking in a single application.

## 🚀 Technical Features & Logic

### 🗓️ Scheduling & Booking Automation
- Real-Time Court Allocator: Built an automated scheduling engine that handles concurrent time-slot allocation, preventing double-booking conflicts and presenting live court availability statuses to end-users.
- Operational Command Center: Engineered a secure backend administrative dashboard allowing facility providers to monitor upcoming bookings, manage dynamic transaction statuses, and keep a paper trail of pending payments.

### 🔒 Authentication & Personalization Engine
- Secure Session Management: Integrated a complete authentication flow (Registration, Login, and Session control) to safely isolate user state and manage credential authorization.
- Dynamic Profile Engine: Developed an asset upload pipeline enabling users to modify account settings and process dynamic profile picture configurations directly onto local storage vectors.

### 📊 Relational Database Design & Quality Assurance
- Relational Schema Mapping: Designed a fully normalized MySQL database schema that resolves complex many-to-many data relationships between Users, Bookings, Court Fields, and Transactions.
- Operational CRUD Implementations: Created a reliable data access layer utilizing structured query scripts to safely perform Create, Read, Update, and Delete actions on live financial and booking records.
- Service Evaluation Loop: Implemented a relational review and rating core that channels structured player feedback straight to the administrative core for continuous facility assessment.
